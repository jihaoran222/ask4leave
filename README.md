# 请假条生成器

一个纯前端的小工具：左边填姓名、学号、起止时间、请假原因、外出地点，右边实时生成请假记录页；可按手机界面 1:1 打印或存为 PDF。

## 用法

双击 `index.html`，用浏览器打开即可。无需安装、无需联网、无需后端。

- 填表，右侧同步变化
- 「打印 / 存为 PDF」→ 打印对话框里选「另存为 PDF」
- 「清空重填」恢复初始状态

## 说明

- 页面复刻的是移动端请假系统的界面样式，**不是任何学校的官方系统**，只是界面练习。
- 状态栏的时间与电量在每次刷新时随机生成。
- 页面内的姓名、学号均为示例数据，与真实人员无关。
- 单文件、零依赖。字体优先使用本机已安装的思源黑体（Noto Sans SC），没有则回退到系统默认字体。

## 部署

纯静态页面，直接把 `index.html` 放进任意静态托管（GitHub Pages、Vercel 等）即可。
